## 一、 全站核心容器與柵格對齊規範 (Master Grid System)

### 1. 全域唯一的 `@utility container`（罐頭網頁嚴絲合縫脊椎線）
全站徹底杜絕在各組件手寫 `max-w-[1240px]`、`max-w-7xl`、`max-w-[1280px]` 等碎片化類名。全域統一在 `src/styles/global.css` 底層初始化：

```css
.site-container,
.container,
.wrapper,
.header-container,

.intro-container {
  width: 100% !important;
  max-width: 1280px !important;   /* 桌面端最大畫布：嚴格鎖定 1280px */
  margin-left: auto !important;
  margin-right: auto !important;
  padding-left: 15px !important;  /* 移動端與桌面端：左右邊距 100% 絕對垂直切齊 */
  padding-right: 15px !important;
  box-sizing: border-box !important;
}
```

### 2. 雙端對齊基準線
* **PC 桌面端 (`≥ 1024px`)**：
  - 畫布最大寬度鎖定為 `1280px`。
  - 垂直參考線：Logo 最左側 = Banner 最左側 = 服務卡片最左側 = 介紹標題最左側 = Footer Logo 最左側。
  - 右側邊界：右側膠囊按鈕 = Banner 最右側 = 第 5 張服務卡片最右側 = Footer 內容最右側。
* **Mobile 移動端 (`< 1024px`)**：
  - 左右內邊距**嚴格鎖定為最大 15px (`px-[15px]`)**。
  - 上下滑動時全站所有元素如同一刀切齊，杜絕忽寬忽窄。

## 二、 頂部 Header 與 頁尾 Footer 規範 (Header & Footer Standards)

### 1. 頂部 Header
* **Logo 區域**：
  - 高度透過 `flex items-stretch` 與 `self-stretch`，Logo 圖片採用 `height: 100%; max-height: 100%; width: auto; object-fit: contain;`，與右側導航自然等高，零固定數值寫死。
  - 左側邊界歸零 (`padding-left: 0; margin-left: 0;`)，確保第一像素精確壓在 1280px 左基準線上。
* **PC 桌面端**：
  - 主菜單字號 **18px**（`font-size: 18px; line-height: 1.5;`），字符間距 **2px**（`letter-spacing: 2px;`）。
  - 藍色置頂圓點 (`nav-dot`) 與文字正上方**水平垂直嚴格居中**。
  - 膠囊按鈕（綠色 WhatsApp / 藍色講座）直接調用**原版官方向量 SVG 檔案**（`icon-whatsapp.svg`, `icon-lecture.svg`），保留原始尺寸比例。
  - 語言切換：地球圖標 +「繁體中文 / 简体中文」+ 下拉展開浮層。
* **Mobile 移動端**：
  - 膠囊按鈕：**完全隱藏**。
  - 語言切換：**極簡直接切換**（繁體頁面僅顯示「地球圖標 + 简」，簡體頁面僅顯示「地球圖標 + 繁」）。
  - 滿屏獨立滾動抽屜：展開高度 `height: calc(100dvh - 68px)`，**內部自帶獨立滾動軸，展開時鎖定底層頁面滾動**；二級子菜單採用雙列膠囊晶片平鋪展示，免除多次點擊。
  - 雙端樣式**嚴格物理隔離**，移動端調整絕不污染 PC 端。

### 2. 頁尾 Footer 與 移動端底欄
* **1280px 對齊基準**：頁尾 Logo、門市地址、營業時間、全站導航地圖最左邊緣，必須與頂部 Logo 100% 垂直對齊。

## 四、 首頁 Banner 輪播規範 (Hero Banner Standards)
